# CLAUDE.md 配置示例

这个示例展示了如何为不同类型的项目配置 CLAUDE.md 文件。

## 示例项目

### 1. Next.js 项目
查看 `nextjs-project/CLAUDE.md` - 适用于 Next.js + TypeScript + Tailwind CSS 项目。

### 2. Python 项目
查看 `python-project/CLAUDE.md` - 适用于 Python + FastAPI + SQLAlchemy 项目。

### 3. React 组件库
查看 `react-library/CLAUDE.md` - 适用于 React 组件库开发。

## CLAUDE.md 最佳实践

1. **保持简洁** - 只包含最重要的信息
2. **定期更新** - 项目变化时及时更新
3. **包含常用命令** - 开发、测试、构建命令
4. **明确编码规范** - 命名约定、代码风格
5. **列出注意事项** - 已知问题、特殊规则

## 使用方法

1. 复制适合你项目的 CLAUDE.md 模板
2. 根据项目实际情况修改
3. 提交到版本控制
4. 让团队成员了解内容

## 模板位置

完整的 CLAUDE.md 模板位于：
```
public/templates/CLAUDE.md
```

可以直接复制使用。
